mango's web is a simple personal portfolio built with vanilla HTML, CSS, and JavaScript. The website fetches real-time weather data for Coimbra using the [Open-Meteo API](https://open-meteo.com/) and dynamically updates the background sky tiles and colors.

Users can switch between Home, Works, About Me, and Contact without page reloads. Project cards open a native `<dialog>` modal with galleries, project descriptions, and external links.

**Live Website:** https://ples487-beep.github.io/mangos-web/  
**Repository:** https://github.com/ples487-beep/mangos-web

## Features

- **Live Coimbra Weather:** Real-time weather integration via Open-Meteo API with drawn pixel art sky tiles (`sun`, `clouds`, `cloudy`, `rain`) animated with CSS `@keyframes`.
- **Single-Page Navigation:** Dynamic section switching without page reloads.
- **Interactive Project Modals:** Native HTML `<dialog>` popups with image galleries and external project links.
- **Responsive Layout:** Adapts between a fixed sidebar on desktop and a stacked top navigation bar on mobile screens.

## Tech Stack

- HTML5
- CSS3 
- Vanilla JavaScript
